# General Rules

Workflow, branching, commit, and PR guidelines that apply to all work in this repository.

## Files

| File | Description |
|------|-------------|
| `workflow.md` | High-level workflow overview — 9-step process from task intake to PR |
| `implementation-workflow.md` | Detailed step-by-step implementation workflow with STOP checkpoints: intake → branch → plan → implement → validate → review → commit → PR → progress |
| `commits.md` | Commit message format (`<type>(<scope>): <description>`), types (feat, fix, refactor, test, docs, chore, style, perf), scopes (mobile, android, ios, api, db, auth, alerts, score, scan), rules |
| `pr-guidelines.md` | Pull request process: base branch (`develop`), description template, CI validation, auto-fix workflow, approval requirements |
| `progress.md` | MVP feature progress tracker — table of all planned features with status (-, IN PROGRESS, DONE, BLOCKED) and dates |
| `project-info.md` | Project metadata: name, description, tech stack, team, key dates |
| `ai-model-selection.md` | Guidance on selecting the right Claude model for different task types |
