# Vue Components

Reusable UI components shared across admin views.

## Files

| File | Description |
|------|-------------|
| `AlertBadge.vue` | Displays an alert severity badge (color-coded chip: CRITICAL=red, HIGH=orange, MEDIUM=yellow, LOW=green) |
| `Navbar.vue` | Top navigation bar with app title and logout button; shown on all authenticated pages |
| `Pagination.vue` | Generic pagination control emitting `page-change` events; used by `UserList`, `UserDetail`, and `ScanHistory` views |
