# Admin Dashboard

Vue 3 + Vite web admin interface for platform management. Served as static files (built to `dist/`) and proxied through the Spring Boot API in development.

## Structure

| Path | Purpose |
|------|---------|
| [`src/`](src/SUMMARY.md) | Application source — components, views, router, API client |
| `dist/` | Production build output (generated by `npm run build`) |
| `index.html` | Vite HTML entry point |
| `vite.config.js` | Vite config — dev server proxy (`/api` → Spring Boot), build output path |
| `package.json` | Dependencies: Vue 3, Vue Router, Axios |

## Build Commands

```bash
npm install          # install dependencies
npm run dev          # dev server with API proxy (port 5173)
npm run build        # production build to dist/
```

## Authentication

Admin token stored in `localStorage` as `adminToken`. Defaults to `"changeme"` if not set. All requests include `Authorization: Bearer <token>` header.
